## 🧠 Flagship Projects

### 🌟 [NovaBrain-V1](https://github.com/Brayan114/NovaBrain-V1)
*A custom, character-level transformer/GPT engine engineered from first principles in PyTorch.*
*   **The Problem:** Vanilla $O(N^2)$ self-attention scales quadratically, blowing up GPU VRAM (e.g., standard baseline requires **2.9 GB** of memory for a single 8,000-token sequence on a T4 GPU).
*   **The Craft:** Designed and implemented a **natively sparse, core-context attention** algorithm that restricts computation to high-salience tokens.
*   **The Impact:** Reduced memory footprint at 8,000 tokens from **2.9 GB to 210 MB**—unlocking long-context reasoning on consumer-grade hardware.
